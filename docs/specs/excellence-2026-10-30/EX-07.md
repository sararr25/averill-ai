## Problem Statement

The desktop summary loses explanations and snippets retained in the richer public result.

## Solution

Show the same verdict, reason and evidence from desktop and companion.

## User Stories

1. As an employee, I want to return to an earlier check, so that I can complete my work confidently without a test guide.
2. As an employee, I want to read why a verdict is unclear, so that I can complete my work confidently without a test guide.
3. As an employee, I want to see the evidence excerpt, so that I can complete my work confidently without a test guide.
4. As an employee, I want to open the cited public page, so that I can complete my work confidently without a test guide.
5. As an employee, I want to see when the check occurred, so that I can complete my work confidently without a test guide.
6. As an employee, I want to recognize public evidence is not company approval, so that I can complete my work confidently without a test guide.
7. As an employee, I want to switch surfaces without losing the reason, so that I can complete my work confidently without a test guide.
8. As an employee, I want to recognize a stale result after editing, so that I can complete my work confidently without a test guide.
9. As an employee, I want to avoid seeing another person’s check, so that I can complete my work confidently without a test guide.
10. As an employee, I want to stop sharing without retaining inappropriate context, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Keep a bounded normalized public-result representation across surfaces.
- Preserve explanation, supporting excerpt, authority and timestamps while excluding model traces.
- Bind results to person/session/context and invalidate stale work state.

## Testing Decisions

- Exercise one public check through both authorized presentations and assert user-visible reason/evidence parity.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
