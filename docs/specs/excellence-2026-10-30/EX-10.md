## Problem Statement

Long preview cards and identical version titles make authoritative documents hard to locate.

## Solution

Find documents in compact indexed results and inspect a selected version with clear authority.

## User Stories

1. As an employee, I want to search by subject, so that I can complete my work confidently without a test guide.
2. As an employee, I want to search by familiar synonyms, so that I can complete my work confidently without a test guide.
3. As an employee, I want to filter by department, so that I can complete my work confidently without a test guide.
4. As an employee, I want to see a current document family, so that I can complete my work confidently without a test guide.
5. As an employee, I want to inspect older versions explicitly, so that I can complete my work confidently without a test guide.
6. As an employee, I want to recognize conflicts, so that I can complete my work confidently without a test guide.
7. As an employee, I want to distinguish personal and company knowledge, so that I can complete my work confidently without a test guide.
8. As an employee, I want to open a highlighted passage, so that I can complete my work confidently without a test guide.
9. As an employee, I want to return to the same results, so that I can complete my work confidently without a test guide.
10. As an employee, I want to clear filters, so that I can complete my work confidently without a test guide.
11. As an employee, I want to review pending material only when authorized, so that I can complete my work confidently without a test guide.
12. As an employee, I want to avoid automatic approval changes, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Render compact document rows and a selected reader with meaningful titles and metadata.
- Group versions into families without changing existing approval or replacement semantics.
- Preserve active search/filter/selection and focus across reader navigation.
- Expose accessible review queues separately from employee lookup.

## Testing Decisions

- Find/open/back tasks across current, superseded, private, pending and conflicting sources in existing authenticated renderer matrix.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
