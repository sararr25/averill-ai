Exact excerpts, provider status and generic prose are presented without a reliable intent-specific answer structure.

## Solution

Return a concise useful answer, traceable evidence and one appropriate next action.

## Implementation Decisions

- Use a shared typed answer envelope consumed by desktop and companion.
- Extend existing public schema rather than introducing a parallel client.
- Keep exact citation checks while allowing validated faithful synthesis in the relevant intent.
- Validate claim support, negations, numbers, conditions, coverage and context freshness.
- Render actions only from local allowlists; model prose is never executable code or an edit.
- Use bounded repair and readable fallback; preserve total call/time budgets.

## Testing Decisions

- Real renderer/IPC answer presentation with synthetic providers; adversarial evidence/claim cases and separate live-provider corpus.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
