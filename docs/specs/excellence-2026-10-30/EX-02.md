## Problem Statement

Passing transport and unit tests does not show whether ordinary questions produce useful answers.

## Solution

Measure intent, relevance, completeness, evidence and recovery using realistic tasks.

## Implementation Decisions

- Create an 80-case evaluation catalogue spanning policy, tool help, visual review, drafts, summaries/comparisons, public research, follow-ups and failure/privacy/context.
- Separate implemented regression assertions from planned evaluation cases; retain baseline failures honestly.
- Reserve unseen paraphrases for holdout evaluation; do not tune all examples into keyword patterns.
- Store synthetic fixtures and content-free aggregate results, not real employee questions.

## Testing Decisions

- Prefer existing assistant renderer/IPC and authenticated contextual flows; add lower-level tests only for security/lifecycle contracts that cannot be exercised reliably above them.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
