## Problem Statement

Finding a previous answer or the next action requires scrolling unrelated content.

## Solution

Use an indexed task workspace with a reachable composer and optional source reader.

## User Stories

1. As an employee, I want to start a new task, so that I can complete my work confidently without a test guide.
2. As an employee, I want to name or recognize the current task, so that I can complete my work confidently without a test guide.
3. As an employee, I want to find a previous conversation, so that I can complete my work confidently without a test guide.
4. As an employee, I want to pin a useful task, so that I can complete my work confidently without a test guide.
5. As an employee, I want to ask a follow-up without losing the answer, so that I can complete my work confidently without a test guide.
6. As an employee, I want to see what work is shared, so that I can complete my work confidently without a test guide.
7. As an employee, I want to change context explicitly, so that I can complete my work confidently without a test guide.
8. As an employee, I want to open evidence without leaving the task, so that I can complete my work confidently without a test guide.
9. As an employee, I want to return from the source reader, so that I can complete my work confidently without a test guide.
10. As an employee, I want to use an informative empty Home, so that I can complete my work confidently without a test guide.
11. As an employee, I want to work in a compact window, so that I can complete my work confidently without a test guide.
12. As an employee, I want to clear own session history, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Implement approved destination structure against the shared answer envelope.
- Keep composer and context reachable without nesting unnecessary scroll regions.
- Start with person-scoped session history; durable content persistence requires explicit retention/visibility design.
- Retain existing accounts, local namespaces and Stop controls.

## Testing Decisions

- Renderer/IPC task creation, navigation, source/back, context switch and logout with synthetic roles; verify visible labels and focus.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
