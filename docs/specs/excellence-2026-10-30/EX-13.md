## Problem Statement

Generic long instructions and exceptional workarounds make simple tool help unnecessarily difficult.

## Solution

Find the right short guide, resume at an applicable step and recover from missing controls.

## User Stories

1. As an employee, I want to find guides by tool, so that I can complete my work confidently without a test guide.
2. As an employee, I want to find guides by task, so that I can complete my work confidently without a test guide.
3. As an employee, I want to recognize the guide’s goal, so that I can complete my work confidently without a test guide.
4. As an employee, I want to resume at an applicable step, so that I can complete my work confidently without a test guide.
5. As an employee, I want to see the expected result, so that I can complete my work confidently without a test guide.
6. As an employee, I want to locate an actually visible control, so that I can complete my work confidently without a test guide.
7. As an employee, I want to recover when a menu is closed, so that I can complete my work confidently without a test guide.
8. As an employee, I want to recover when controls are ambiguous, so that I can complete my work confidently without a test guide.
9. As an employee, I want to avoid mobile-only desktop instructions, so that I can complete my work confidently without a test guide.
10. As an employee, I want to see exceptional workarounds only when needed, so that I can complete my work confidently without a test guide.
11. As an employee, I want to exit without losing work, so that I can complete my work confidently without a test guide.
12. As an employee, I want to inspect the official help source, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Use versioned task-specific authored guide definitions with evidence and supported target semantics.
- Only outline a uniquely resolved visible control; no guessed coordinates or host clicks.
- Validate platform/condition relevance and keep illustrations explicitly exemplary.

## Testing Decisions

- Guide start/resume/missing/ambiguous/exit through existing extension harness plus real supported-control rehearsal.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
