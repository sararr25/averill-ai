## Problem Statement

Primary AI actions are hidden within Current work and More, while Home can offer only empty lists.

## Solution

Provide clear indexed entry points and a productive first screen without a mandatory tour.

## User Stories

1. As an employee, I want to find where to ask a question, so that I can complete my work confidently without a test guide.
2. As an employee, I want to find public research, so that I can complete my work confidently without a test guide.
3. As an employee, I want to start a work check, so that I can complete my work confidently without a test guide.
4. As an employee, I want to resume an active task, so that I can complete my work confidently without a test guide.
5. As an employee, I want to locate the company library, so that I can complete my work confidently without a test guide.
6. As an employee, I want to locate Learn, so that I can complete my work confidently without a test guide.
7. As an employee, I want to find connections and settings, so that I can complete my work confidently without a test guide.
8. As an employee, I want to act even with no assigned tasks, so that I can complete my work confidently without a test guide.
9. As an employee, I want to use navigation on a narrow window, so that I can complete my work confidently without a test guide.
10. As an employee, I want to understand the active destination, so that I can complete my work confidently without a test guide.
11. As an employee, I want to navigate entirely by keyboard, so that I can complete my work confidently without a test guide.
12. As an employee, I want to complete a first-click task without guidance, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Prototype Home, Assistant, My work, Library and Learn within the approved Companion identity.
- Keep public research visible from Assistant and settings in a stable account/connection location.
- Validate labels using outcome-based first-click tasks before runtime migration.
- At narrow widths use labelled destinations and explicit Back navigation.

## Testing Decisions

- First-click and navigation tasks on a reviewable prototype plus keyboard and narrow/wide inspection; do not claim a human winner from synthetic checks.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
