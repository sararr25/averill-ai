## Problem Statement

An email can be checked as Canva text, stale Learn errors contradict progress, and document labels can contradict their authority.

## Solution

Show the correct current work type, current learning state and unambiguous source authority.

## User Stories

1. As an employee, I want to recognize the shared email as email, so that I can complete my work confidently without a test guide.
2. As an employee, I want to see when a selected work type is an explicit override, so that I can complete my work confidently without a test guide.
3. As an employee, I want to reset an override when the shared context changes, so that I can complete my work confidently without a test guide.
4. As an employee, I want to see current measurements separately from history, so that I can complete my work confidently without a test guide.
5. As an employee, I want to see learning errors clear after the condition changes, so that I can complete my work confidently without a test guide.
6. As an employee, I want to understand which steps still need attention, so that I can complete my work confidently without a test guide.
7. As an employee, I want to distinguish personal notes from company policy, so that I can complete my work confidently without a test guide.
8. As an employee, I want to see approval conflicts sent for explicit review, so that I can complete my work confidently without a test guide.
9. As an employee, I want to keep existing approvals unchanged during diagnosis, so that I can complete my work confidently without a test guide.
10. As an employee, I want to recover without reading an internal exception, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Reproduce each audit observation in an isolated workspace before fixing it.
- Bind inferred work type and explicit override to the observed identity.
- Keep approval metadata authoritative; flag contradictory content rather than auto-approving or revoking sources.
- Model current measurements separately from historical progress and transient errors.

## Testing Decisions

- Context changes, rule-set selection and learning/authority recovery; reproduce email versus Canva mismatch and stale measurement/error cases.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
