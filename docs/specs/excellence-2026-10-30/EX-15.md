## Problem Statement

A global connected status does not explain whether retrieval, generation or validation caused a poor answer.

## Solution

Diagnose answer failures accurately without collecting employee content by default.

3. As an employee, I want to retry an unavailable service, so that I can complete my work confidently without a test guide.
4. As an employee, I want to report an irrelevant answer, so that I can complete my work confidently without a test guide.
5. As an employee, I want to report missing coverage, so that I can complete my work confidently without a test guide.
6. As an employee, I want to report a wrong source, so that I can complete my work confidently without a test guide.

9. As an employee, I want to keep documents out of diagnostic logs, so that I can complete my work confidently without a test guide.
10. As an employee, I want to understand retention and clearing, so that I can complete my work confidently without a test guide.
11. As an employee, I want to know which model/version was tested, so that I can complete my work confidently without a test guide.
12. As an employee, I want to avoid automatic sharing of feedback, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Record content-free stage, latency, model/version and failure categories locally where possible.
- Define visibility and retention before persistence.
- Feedback must not send messages or employee text without explicit authorization.

## Testing Decisions

- Exercise failure categories and inspect outbound/log records for absence of questions, drafts, sources and credentials.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
