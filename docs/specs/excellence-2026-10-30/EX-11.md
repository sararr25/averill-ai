## Problem Statement

A long companion scroll mixes questions, findings, lessons and technical details.

## Solution

Use one stable panel with indexed Ask, Checks and Guide views and one clear current action.

## User Stories

1. As an employee, I want to switch from answer to checks, so that I can complete my work confidently without a test guide.
2. As an employee, I want to start the relevant guide, so that I can complete my work confidently without a test guide.
3. As an employee, I want to see one active step, so that I can complete my work confidently without a test guide.
4. As an employee, I want to open the guide index, so that I can complete my work confidently without a test guide.
5. As an employee, I want to return to my unfinished question, so that I can complete my work confidently without a test guide.
6. As an employee, I want to keep Stop sharing reachable, so that I can complete my work confidently without a test guide.
7. As an employee, I want to minimize without automatic reopening, so that I can complete my work confidently without a test guide.
8. As an employee, I want to find the highest-priority issue, so that I can complete my work confidently without a test guide.
9. As an employee, I want to see which carousel pages remain unread, so that I can complete my work confidently without a test guide.
10. As an employee, I want to open supporting sources, so that I can complete my work confidently without a test guide.
11. As an employee, I want to use the panel with keyboard, so that I can complete my work confidently without a test guide.
12. As an employee, I want to recover when a target cannot be located, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Adapt the existing single-panel companion; retain sticky minimization.
- Keep person/tab/design/page identity and Stop outside scrolling content.
- Preserve question state across views and separate current findings from past results.
- Guides remain user-driven and DOM-bounded; no automatic Canva controls.

## Testing Decisions

- Existing extension/bridge/renderer harness with synthetic Canva; real installed extension acceptance remains a separate receipt.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
