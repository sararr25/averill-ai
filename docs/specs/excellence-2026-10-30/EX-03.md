## Problem Statement

Natural tool requests, summaries and short follow-ups can fall into company lookup and dead-end answers.

## Solution

Understand the task and carry only relevant current context, with a useful clarification when needed.

## User Stories

1. As an employee, I want to describe putting a photo inside a shape, so that I can complete my work confidently without a test guide.
2. As an employee, I want to ask whether selected text is readable, so that I can complete my work confidently without a test guide.
3. As an employee, I want to ask how to change a color without repeating Canva, so that I can complete my work confidently without a test guide.
4. As an employee, I want to say “and on Instagram?” after a task, so that I can complete my work confidently without a test guide.
5. As an employee, I want to ask for a summary without receiving a company lookup, so that I can complete my work confidently without a test guide.
6. As an employee, I want to ask for differences between versions, so that I can complete my work confidently without a test guide.
7. As an employee, I want to ask several related goals without losing one, so that I can complete my work confidently without a test guide.
8. As an employee, I want to ask for a company requirement without receiving optional advice as policy, so that I can complete my work confidently without a test guide.
9. As an employee, I want to switch work contexts without inheriting the wrong topic, so that I can complete my work confidently without a test guide.
10. As an employee, I want to ask a follow-up after permissions change and receive fresh context, so that I can complete my work confidently without a test guide.
11. As an employee, I want to receive a specific clarification when no tool is known, so that I can complete my work confidently without a test guide.
12. As an employee, I want to continue offline without provider calls, so that I can complete my work confidently without a test guide.

## Implementation Decisions

- Represent intent, goals, tool, required context and unresolved ambiguity explicitly.
- Keep classification local; no arbitrary question is sent on the closed public-help route.
- Scope continuation to authenticated person, source authority and active work identity.
- Distinguish operational help, policy, draft, summary, comparison, research and review.
- Preserve explicit company rules and content-bound consent.

## Testing Decisions

- Question to preview to answer in the existing renderer/IPC; authenticated browser flow for selected-field and follow-up behavior.
- Test observable behavior and employee-visible results, not private implementation structure. Prefer the existing authenticated renderer/IPC question → outbound preview → answer seam, following the Pro renderer and contextual bridge prior art. Preserve isolated synthetic accounts; company/public evidence, Stop/logout and content-bound consent are mandatory. The owner confirmed these testing seams on 30 October 2026.

## Out of Scope

Autonomous send, export or publication; arbitrary desktop observation or control; new screenshot/OCR permissions; automatic source approvals; cross-person memory; real employee data in Tavily; replacing human usability or real-platform acceptance with synthetic tests.
