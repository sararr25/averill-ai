## Verification against points 1–3

- **Passed:** 44 Node tests; isolated Electron feedback, external observation and task-review smoke; native TextEdit Accessibility read/live edit/Stop; real Chrome OCR read/live edit/Stop using a local synthetic editor; arm64 package build and packaged-resource feedback/external smoke. The external email smoke imported and approved a synthetic Marketing rule, cited the forbidden phrase, cleared it after a human edit, invalidated it on source revocation and rejected review after Stop.
- **Still unverified:** actual Substack/email marketing, LinkedIn, Instagram and Canva accounts; OS permission revocation/denial; full-screen and two physical displays; browser private mode/cross-origin state; live Nebius task request. The Chrome test proved a real browser window with synthetic page text, not platform draft integration. The TextEdit test proved one native app, not all Accessibility controls.
- **Missing implementation for complete acceptance:** opt-in DOM field adapter or official draft integration, field/selection-aware edit pause, broader audience/date/asset/procedure rules and visual verification. Do not present a six-second OCR poll as field-aware context.

## Evidence gates

1. The selected window is named in Averill and the floating control. Observation has a method (`accessibility` or `ocr`), timestamp, bounded text and confidence label. No company source or model verdict is implied by observed text alone.
2. A live edit in one browser editor and one native application changes the local observation after a pause. No keystroke-by-keystroke interruption or provider request occurs. If macOS Accessibility is unavailable, visible-text OCR is the explicit fallback.
3. Stop from the main window and from the floating control both end polling and remove transient observed text. Close, sign-out, account change, permission denial and app restart do not leak the previous employee's context. The control remains usable across monitors and full-screen windows.
4. Manual acceptance needs disposable accounts and actual external editors for Substack, LinkedIn, Instagram and Canva. Do not substitute the supplied Electron fixtures for that proof. Record unavailable accounts or OS permission as unverified, not passed.

No real emails, posts, bookings or employee decisions are made in this matrix. Complete task interpretation, automatic correction suggestions, Tavily claim verdicts and broader learning remain tracked in [COMPLETE_VISION_PLAN.md](COMPLETE_VISION_PLAN.md).
