## Import and review

1. Create Elseweek as Alex Holm. Add all six department people; departments are created by adding people.
2. As admin, choose Marketing in **Import department**, visibility **Propose to department**, version **1**. Use multi-file import to select the four Marketing documents other than `current-brief.md`. Then import `Marketing/current-brief.md` separately with version **2**. All five arrive pending. Do not infer workspace metadata or approval from the text inside a file.
3. Switch to Maya and open/review each source before approving. Set campaign brief priority 90, LinkedIn guidance 85, calendar 80, brand/legal 70, company context 60.
4. As Alex, import the `Operations` folder with department Operations/version 1, then `People` with department People/version 1. Noah and Lina review and approve their respective department sources. Give procedure/guide priority 80 and company context 60.
5. As Emma, import only `Proposals/marketing-personal-note-v1.md` with private visibility/version 1. Switch to Maya: the note must be invisible. Switch to Emma, propose it, then Maya reviews and approves it.
6. Archive is optional. Import `Archive/old-brief.md` separately at version 1 and mark **Supersede** after temporary approval; do not leave it approved. Prefer the already supplied Campaign Files v1/v2 scene for the version comparison. Never import this whole pack root as one department.

## Employee visibility and restart

Emma sees approved Marketing context and her own private/pending proposal; no Operations/People source. Oliver sees approved Operations documents; Freja sees approved People documents. Leads manage only their own department. Administrator sees proposed department documents across departments but not other people's private notes. Pending imported files are not authoritative even when their text says APPROVED. Restart must retain people, imported copies, approval, priority and version.

The brand context is identically copied across all departments because company-wide source scope is not implemented. Folder import uses one selected department and version for every file; it does not infer metadata from headings. No real authentication or synchronization is claimed.
