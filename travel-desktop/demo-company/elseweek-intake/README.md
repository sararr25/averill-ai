# Elseweek mixed-format onboarding intake

Upload all six company files in this directory through **Add company files**. Do not select this README as company policy. The workbook supplies the three Marketing accounts; owner setup supplies the fourth. All identities/emails are fictional and use the reserved `.example` domain. No passwords are embedded in documents.

Follow `docs/ONBOARDING_TUTORIAL.md` in the repository root for owner setup, Nebius interpretation, review, saved login documents and four logins. The older `demo-company/elseweek/` remains an alternative manual import pack.

Files: staff workbook (.xlsx), company brand context (.svg), campaign brief v2 (.pdf), LinkedIn guidance (.md), Operations procedure (.md), People onboarding (.md). SVG palette and mark derive from the existing Elseweek website design system. Campaign dates match the approved supplied fixtures. Account/job profiles: Maya Jensen / Marketing manager; Emma Larsen / Marketing strategy employee; Oscar Lind / Content creator. Alex Holm is the owner created during setup.

No file auto-approves itself. Personnel copies are private to the owner. Company-wide brand guidance and department documents require explicit confirmation. Existing account emails are excluded by default. After confirmation, generated account/password documents are saved automatically on this Mac; reopen them through Account access → Open login documents.
